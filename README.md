# ERA Studio — Downloads / Téléchargements

**Free** tool to explore ERA5 and ERA5-Land climate data: maps, time series, statistics, wind rose, missing-data
handling and exports — no coding required. Works offline with your own NetCDF / GRIB files.

Outil **gratuit** pour explorer les données climatiques ERA5 et ERA5-Land : cartes, séries temporelles, statistiques,
rose des vents, traitement des données manquantes et exports, sans écrire de code. Fonctionne hors ligne avec vos
propres fichiers NetCDF / GRIB.

## ⬇️ Download / Télécharger

**[Latest version for Windows → Releases](https://github.com/bouhaddanihed-eng/era-studio-downloads2/releases/latest)**
Download `ERA-Studio-portable-windows.zip`, unzip it, then double-click **ERA Studio.exe**.
Téléchargez `ERA-Studio-portable-windows.zip`, dézippez-le, puis double-cliquez sur **ERA Studio.exe**.

## Requirements / Prérequis
- Windows 10 or 11, **64-bit** / Windows 10 ou 11, **64 bits**
- 8 GB RAM recommended / 8 Go de RAM conseillés
- No installation, no administrator rights / Aucune installation, aucun droit administrateur
- Internet only for Copernicus (CDS) downloads and online maps / Internet seulement pour le téléchargement
  Copernicus (CDS) et les cartes en ligne

## If Windows shows a warning / Si Windows affiche un avertissement
The program is not digitally signed yet. If you see *“Windows protected your PC”*: click **More info → Run anyway**.
Le programme n'est pas encore signé numériquement. Si vous voyez « Windows a protégé votre ordinateur » :
cliquez sur **Informations complémentaires → Exécuter quand même**.
